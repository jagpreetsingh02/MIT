# RootLine
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Delegated by the supplied specification. React/TypeScript, Fastify, Node 24 SQLite. A single container serves the API and built UI; replaceable connector/cache boundaries.
## Users
Developers tracing vulnerable dependencies to applications and services; hackathon viewers following a two-minute repository-to-ripple demonstration.
## Product Purpose
Map dependency graphs, rank deterministic risk, simulate reverse dependency impact, and export SPDX 2.3 JSON.
## Capabilities and Constraints
npm, PyPI and Maven inputs. Preserve exact versions, PURLs and provenance. Distinguish incomplete resolution and unavailable vulnerability data. No LLM in risk decisions. Signed GitHub webhooks. Reviewed PR-only update automation.
## Evidence on Hand
The supplied specification. No separate React reference was attached. Demo graph and advisories must be clearly marked illustrative.
## Product Principles
Explain every score. Separate facts from derivation. Keep the dependency graph primary. Never claim an unchecked dependency is secure.
