# RippleGuard visual system

Light technical workspace for extended daytime investigations. Graph is the main analytical surface; supporting facts stay adjacent rather than competing with it.

Warm rust identifies the selected dependency and propagation. Deep green-gray represents application services; risk colors have text labels. White surfaces, pale gray canvas, restrained rules. Geist for interface, Geist Mono only for versions/PURLs/measurements.

Compact navigation, repository discovery and project confirmation, visible scan stages, four summary measures, top priority, focused dependency graph with adjacent inspector, then a ranked table. Narrow screens stack the inspector and retain a scrollable graph with an equivalent accessible inventory. Every graph node supports keyboard selection. Reduced motion disables propagation animation.

Preserves the existing identity and prioritizes the repository-to-ripple journey from the current developer and hackathon brief.
